# Lucky Draw System Python

## Project Overview

A Python-based lucky draw system that randomly selects winners from a participant list.

## Features

* Random Winner Selection
* Multiple Winners
* No Duplicate Winners
* Ranking System

## Technologies Used

* Python
* Random Module
